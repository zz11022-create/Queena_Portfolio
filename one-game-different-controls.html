Assistive Design · Interaction concept

One Game, Different Controls

A classroom game concept for comparing how different control layouts affect the same task.

See the control comparison ↓

Hold the game constant

The brief proposes one star-collection arena with identical movement and scoring across rounds. The control scheme changes, and adaptive configuration gets time before the scored round begins.

Design intent

The exercise invites players to describe how a layout works for them. The available artifact is the design brief and control reference.

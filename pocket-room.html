Pocket Room

A miniature room-building game where each player can decide what a comfortable corner looks like.

Play the Unity build ↗

Place, rotate, rearrange

Furniture tools let players compose a room from the same small set of options. The project reworks a Unity tutorial so each selection places one piece at a time.

Collaboration

Built with Iris for Hypercinema. The tiny room makes the tension between comfort and constraint part of the interaction.

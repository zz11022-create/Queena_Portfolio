Same Behavior, Different Story

A thesis experiment exploring how context and model choice change the stories language models tell about the same animal behavior.

See the comparison ↓

Hold the observation constant

Queena used Ollama and JavaScript to compare Llama 3.2 and Qwen3 across prompts with no context, routine context, emotional context, or unrelated context. The notebook documents 32 responses across the exploratory runs.

Where the evidence changes

In one run the observation described a dog touching a drawer. The model described the dog as interacting with an unrelated envelope introduced by the prompt. The result prompted a design distinction between observed events, inferences with evidence, and invented observations.

Design implication

An interface can show the evidence behind each interpretation and keep alternative explanations visible. The small study offers examples of model behavior under these prompts.

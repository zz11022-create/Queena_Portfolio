Sparrow Urbanism

A tangible ecological game in which changes to a physical city model shape a real-time house sparrow simulation.

Build, observe, revise

Participants rearrange physical city blocks. Sensors carry those changes into the simulation, where participants can observe a response and try a different layout.

A shared cause and effect

The installation uses a shared model to make the relationship between urban planning and habitat visible through play.
